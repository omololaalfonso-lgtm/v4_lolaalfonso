Designed an interactive HR analytics dashboard to analyze employee attrition, performance, and workforce trends.

- Built a relational data model from main and lookup tables
- Performed data cleaning and transformation using Power Query
- Developed KPIs to track attrition rate, performance, and department trends
- Delivered visual insights to support HR decision-making

Impact: Enabled faster identification of high-risk attrition groups and workforce patterns.
